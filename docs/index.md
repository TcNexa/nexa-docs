# neXa Documentation

**neXa is an industrial automation framework for Beckhoff TwinCAT 3, designed to reduce development time and standardize machine software development.**

neXa provides reusable libraries and common software patterns for developing industrial machines and automation systems.

---

## What is neXa?

Industrial automation projects repeatedly require the same fundamental functionality:

- Device control
- Pneumatic cylinders
- Valves
- Motion
- Communication
- Diagnostics
- HMI integration
- Simulation
- Machine sequences

neXa provides reusable components for these common automation tasks.

The goal is simple:

> **Spend less time rebuilding standard functionality and more time developing the machine.**
